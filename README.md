# Todo-sobre-los-virus
🛡️ Investigación: Virus Informáticos
📚 Introducción
Los virus informáticos son programas maliciosos que pueden afectar el funcionamiento de un dispositivo, dañar archivos, robar información o alterar el sistema.

En esta práctica se investigan diferentes tipos de virus informáticos, sus características, los daños que pueden ocasionar y algunas medidas de protección. También se incluyen comandos de Windows que permiten revisar el estado del equipo.

⚠️ Importante: Este proyecto tiene fines educativos. No se utiliza malware real ni se realizan acciones que puedan dañar el equipo.

🦠 Tipos de virus informáticos
1. Virus de archivo
Infecta archivos ejecutables del equipo. Cuando se abre un archivo infectado, el virus puede propagarse a otros archivos y provocar errores o pérdida de información.

2. Virus de sector de arranque
Afecta el sector de arranque de un dispositivo de almacenamiento. Puede provocar problemas e impedir que el sistema operativo se inicie correctamente.

3. Virus residente
Permanece activo en la memoria del equipo y puede infectar archivos mientras se utilizan. Puede causar lentitud y errores en diferentes programas.

4. Virus de acción directa
Actúa cuando se ejecuta un archivo infectado y busca otros archivos para infectarlos. Generalmente no permanece de forma permanente en la memoria.

5. Virus de macro
Utiliza macros de documentos para propagarse. Puede modificar documentos o realizar acciones no deseadas cuando se abre un archivo infectado.

6. Virus polimórfico
Puede modificar parte de su código para dificultar su detección por algunos programas de seguridad.

7. Virus multipartito
Puede infectar diferentes partes de un sistema, como archivos y sectores de arranque. Esto le permite propagarse de diferentes maneras.

8. Virus de sobrescritura
Sobrescribe el contenido de archivos, provocando que la información original pueda perderse o quedar dañada.

9. Virus de script
Utiliza scripts o archivos de comandos para ejecutarse y propagarse. Puede modificar configuraciones o realizar acciones no autorizadas.

10. Virus de red
Puede propagarse mediante conexiones de red y afectar a otros dispositivos conectados, provocando problemas de seguridad e interrupciones.

🛡️ Categorías de malware
No todos los programas maliciosos son técnicamente virus. El término general utilizado es malware.

🦠 Virus
Se adjunta a archivos y puede propagarse cuando estos son ejecutados.

🪱 Gusano
Puede propagarse automáticamente entre diferentes equipos mediante redes.

🎭 Troyano
Se presenta como un programa aparentemente legítimo, pero puede realizar acciones maliciosas.

👁️ Spyware
Puede recopilar información del usuario sin su autorización.

📢 Adware
Muestra publicidad no deseada y puede afectar la experiencia del usuario.

🥷 Rootkit
Busca ocultar procesos o componentes maliciosos dentro del sistema.

⌨️ Keylogger
Registra las pulsaciones del teclado y puede comprometer información.

🔒 Ransomware
Puede bloquear o cifrar información y exigir un pago para permitir su recuperación.

🛡️ Medidas de protección
Para mantener un equipo protegido se recomienda:

Utilizar un antivirus actualizado.
Mantener Windows actualizado.
No abrir enlaces sospechosos.
Utilizar contraseñas seguras.
Realizar copias de seguridad.
Mantener activo el firewall.
Descargar programas únicamente desde fuentes confiables.
Evitar abrir archivos desconocidos.
No conectar dispositivos USB desconocidos.
Realizar análisis de seguridad periódicamente.
